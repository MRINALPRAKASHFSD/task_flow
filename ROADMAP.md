# Roadmap

This document outlines planned improvements and future directions for TaskFlow.
Items are grouped by release. Priorities may shift based on community feedback.

> **Note:** Dates are targets, not commitments.

---

## v1.1.0 — Due Dates

- [ ] Add an optional due date field to the task model.
- [ ] Visual indicator (overdue badge) for tasks past their due date.
- [ ] Sort tasks by due date as an alternative sort order.
- [ ] `CHANGELOG.md` entry.

---

## v1.2.0 — Tags / Labels

- [ ] Allow users to create custom tags and assign them to tasks.
- [ ] Filter by tag in the sidebar.
- [ ] Tag management UI (create, rename, delete).

---

## v1.3.0 — Drag-and-Drop Reordering

- [ ] Drag-and-drop task reordering using the HTML Drag and Drop API.
- [ ] Persist custom order to LocalStorage.
- [ ] Keyboard-accessible reordering alternative.

---

## v1.4.0 — Subtasks

- [ ] Add a list of subtasks (checklist items) within each task.
- [ ] Show subtask completion progress on the task card.

---

## v2.0.0 — Progressive Web App

- [ ] Add a Web App Manifest.
- [ ] Implement a Service Worker for offline support.
- [ ] Install-to-home-screen capability.

---

## Future / Backlog

- Import and export tasks as JSON.
- Keyboard shortcut reference overlay.
- Undo/redo for task mutations.
- Optional sync via the browser's built-in storage API or a self-hosted endpoint.

---

## Completed

- [x] v1.0.0 — Initial release with full task management, theming, filtering, search, LocalStorage, CI, tests and documentation.
